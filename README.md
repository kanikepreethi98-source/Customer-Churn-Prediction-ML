# 🚀 Customer Churn Prediction (Machine Learning Project)

## 📌 Objective
To predict whether a customer will churn using supervised machine learning models.

---

## 📂 Dataset
- Source: Kaggle (Telco Customer Churn)
- Features: 20
- Target: Churn (Yes/No)

---

## ⚙️ Methods
- Data preprocessing (encoding, scaling)
- Train-test split (80/20)
- Models used:
  - Logistic Regression
  - Random Forest

---

## 📊 Results

| Model | Accuracy | F1 Score | ROC-AUC |
|------|---------|---------|--------|
| Logistic Regression | 0.9179 | 0.56 | 0.7793 |
| Random Forest | 0.9627 | 0.8148 | 0.9106 |

---

## 🏆 Conclusion
Random Forest performed better with higher F1 Score and ROC-AUC, making it the best model for this problem.
